Stage 2 decoding:

- Added static location/background decoding in `runtime/knightlore.js`.
- The current room's static location entry is found by scanning the location table from `0x6251` to `0x6BD0`.
- Background ids are read from the room entry until the `0xFF` terminator.
- Each background id is resolved through the background pointer table at `0x6CE2`.
- Background records are decoded as 8-byte sprite records:
  - sprite id;
  - high-resolution X/Y/Z position;
  - dimension X/Y/Z;
  - raw representation flags.
- Added semantic background classifications for:
  - arches `0x00..0x07`;
  - portcullises/rejas `0x08..0x0B`;
  - wall presets `0x0C..0x0E`;
  - tree room/fillers `0x0F..0x11`;
  - fixed backgrounds and high arches `0x12..0x17`.

Dynamic visual records:

- Corrected the dynamic visual parser to use the documented slot spacing:
  - first visual record at `0x5C88`;

- Preserved the old `room.sprites` alias so the existing hidden candidate panel can still work.
- The parser now treats byte 4 as dimension X, byte 5 as dimension Y/depth, and byte 6 as dimension Z/height.
