# Knight Lore 2026

A modification/hack of the Knight Lore for ZX Spectrum, running 
on the JSSpeccy 3 emulator for the browser. This project is simply 
a rewrite of the work originally done by Ricard Galvany in 2006. You can 
find the original project, called Knight Lore 2006, here:
https://ima.udg.edu/~dagush/Projects/KnightLore2006/

IMPORTANT: I am using the personal project as a test of "vibe coding", and
I am tying to avoid "touching" any code, so, please, if you are interested
do not ask questions I would not be able to answer. However, you might be 
interested in reading our development process, which I tried to faithfully 
capture in the Docs folder through the Plan*.txt files, and moreover, the 
logbook.txt file. I hope you enjoy the reading!

WARNING: This project was built for entertainment purposes only, is not 
intended to produce a faithful representation of the original game, and 
it has definitely a lot of room to improve. Take it more as a 
proof-of-concept than a real finished product. 

This code is completely, absolutely and totally experimental. Use 
at your own risk!!!
